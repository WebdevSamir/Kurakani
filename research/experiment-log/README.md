# Experiment Log

One Markdown file should be created for each experiment.

Recommended naming:

`EXP-YYYY-MM-DD-short-name.md`

Each experiment file should include:

- objective
- hypothesis
- system configuration
- dataset/corpus
- implementation commit
- metrics
- results
- error analysis
- conclusion
- next action

Do not overwrite old experiment results. Treat experiment records as an append-only research history.
